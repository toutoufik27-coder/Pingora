# Kinfield: Grow Together (Roblox)

لعبة مزرعة اجتماعية على روبلوكس: كل سيرفر وادٍ من 8 مزارع متجاورة، لكل مزرعة أرض مختلفة،
والجيران يربحون أكثر عندما يتبادلون ويلتقطون ويبنون معًا. وثيقة التصميم الكاملة موجودة في
Claude Docs (تبويب "نسخة روبلوكس").

كل العالم والواجهات مبنية بالكود، فلا تحتاج أن ترسم أي شيء في Studio قبل التجربة.

## التشغيل لأول مرة

1. ثبّت [Rojo](https://rojo.space/docs/v7/getting-started/installation/):
   - إضافة Rojo في VS Code، أو أداة `rojo` عبر Rokit/Aftman.
   - وإضافة Rojo داخل Roblox Studio (من موقع Rojo).
2. انسخ المستودع وافتح المجلد:
   ```
   git clone <repo> && cd <repo>
   git checkout ccr-3fd94141-uhrjvi
   ```
3. إما مزامنة حية:
   ```
   rojo serve
   ```
   ثم في Studio افتح مكانًا فارغًا (Baseplate) واضغط Connect في إضافة Rojo.
   أو بناء ملف مباشرة:
   ```
   rojo build -o Kinfield.rbxl
   ```
   ثم افتح `Kinfield.rbxl` في Studio.
4. احذف الـ Baseplate الافتراضي إن وُجد (العالم يبني أرضه بنفسه).
5. في Game Settings:
   - **Security → Enable Studio Access to API Services**: لتجربة الحفظ والسوق. بدونها تعمل
     اللعبة بحفظ مؤقت في الذاكرة فقط.
   - **Places → Max Players = 10**: 8 مزارعين + 2 زوار.
6. اضغط **Play**. للتبادل والالتقاط جرّب **Test → Local Server** مع لاعبَين أو 3.

## ما تحتاج ضبطه قبل النشر

- **منتجات Robux:** أنشئ الـ Game Passes والـ Developer Products في Creator Dashboard، ثم ضع
  أرقامها في `src/shared/Config/Products.luau`. الرقم 0 يعني أن المنتج معطّل.
- **العرض المباشر:** صاحب اللعبة يكتب `/liveshow` في الدردشة فتبدأ زخة شهب في كل السيرفرات.
  لإضافة أشخاص آخرين: `EventService.ADMINS` في `src/server/Services/EventService.luau`.
- **الأرقام والتوازن:** كلها في `src/shared/Config/` (Economy, Crops, Animals, Workshops...).

## بنية المشروع

| المجلد | المحتوى |
| --- | --- |
| `src/shared/Config` | كل المحتوى والأرقام: الأراضي، المحاصيل، الطقس، الحيوانات، الورش، المناطق، المشاريع، المهام، المنتجات، النصوص (عربي + إنجليزي) |
| `src/shared/Logic` | منطق صافٍ مختبَر: النمو، الأسعار، الطفرات، التربية، المتجر، الالتقاط، التبادل |
| `src/server/World` | بناء الوادي والمزارع والمناطق ونماذج المحاصيل بالكود |
| `src/server/Services` | الحفظ، المزارع، الزراعة، الطقس، المتاجر، الحيوانات، الورش، التبادل، السوق، المشاريع، الاستكشاف، الأحداث، المهام، إعادة البداية، المشتريات |
| `src/client` | الواجهة (مبنية بالكود)، التحكم في الأدوات، اللوحات، النصوص والتأثيرات |
| `tests` | اختبارات المنطق والنصوص |

## الفحص والاختبارات

```
./scripts/check.sh
```

يفحص صياغة كل ملفات Luau باستعمال مترجم Luau الحقيقي، ويشغّل الاختبارات. يبني أداة صغيرة
بـ Rust أول مرة (يحتاج `cargo`). هذا الفحص لا يعوّض التجربة داخل Studio.

## المبادئ الثابتة

- لا طاقة، ولا مخزن يوقف اللعب.
- لا صناديق عشوائية مدفوعة، ولا بذور أو تسريع نمو مدفوع.
- لا شيء مدفوع يؤثر على لاعب آخر.
- الالتقاط يفيد الطرفين: المالك يحتفظ بـ 85%، والملتقط يحصل على 30% إضافية.
- الثعالب لا تُفقد أحدًا شيئًا: المحصول يعود لصاحبه دائمًا.
- التبادل عبر نافذة آمنة فيها تأكيد من الطرفين وعدّ تنازلي 5 ثوانٍ.
- كل منطق الاقتصاد على الخادم، والحفظ بقفل جلسة يمنع نسخ الأغراض.

حالة ما أُنجز وما بقي: [docs/STATUS.md](docs/STATUS.md).
